<center><p style="text-align: center;">Crafting stairs in the crafting table will yield six stairs instead of four to match the number of stairs you would get using a stonecutter.</p>
<p style="text-align: center;"><img src="https://i.imgur.com/CuHq65H.png"/></p></center>
<details>
<summary><strong>Configuration</strong></summary>
<p>You can configure this mod directly in-game or edit the JSON file <code>config/sixstairs.json</code> in your profile folder. Please note that any changes will require restarting Minecraft to take effect.</p>
<center><p style="text-align: center;"><p style="text-align: center;"><b>stairAmount</b> - determines how many stairs you get from crafting</p>
<p style="text-align: center;"><p style="text-align: center;"><b>blockStairsList</b> - list of blocks and the corresponding stairs you can craft from them</p></center>
</details>
